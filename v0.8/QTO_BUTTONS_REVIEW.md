# QTO 按鈕功能整理草稿

用途：整理目前 Ribbon 與操作面板中的功能，方便重新命名、合併、刪除或調整流程。

## 建議判斷欄位

- `保留`：是否保留在主要 UI。
- `位置`：建議放在哪個面板或流程。
- `按鈕名稱`：使用者看到的中文名稱。
- `指令`：AutoCAD 內部指令名稱。
- `是否改圖`：會不會修改圖面物件、圖層或 XData。
- `用途`：使用者角度的功能說明。
- `備註 / 待調整`：可填要合併、改名或刪除的意見。

## 可能的簡化方向草稿

### 方案 A：保留完整功能，但分成 4 個區塊

1. `主要流程`
   - 操作面板
   - 一鍵連接
   - 指定線槽
   - 批次線槽尋路

2. `報表`
   - 重算長度
   - 用線明細
   - 資料檢查

3. `修復`
   - 錯誤上色
   - 清除上色
   - 解除配線
   - 改綁配線

4. `進階`
   - 出線口清單
   - 查出線口
   - 查配線
   - 測試 XData
   - 載入測試

### 方案 B：正式使用者只保留 8 個按鈕

| 面板 | 按鈕 | 指令 |
|---|---|---|
| 流程 | 操作面板 | `QTO_PANEL` |
| 流程 | 一鍵連接 | `QTO_CREATE_CONNECTIONS` |
| 線槽 | 指定線槽 | `QTO_MARK_TRAY` |
| 線槽 | 批次線槽尋路 | `QTO_BATCH_ROUTE_BY_TRAY` |
| 報表 | 重算長度 | `QTO_RECALC_WIRE` |
| 報表 | 用線明細 | `QTO_EXPORT_JB_SUMMARY` |
| 檢查 | 資料檢查 | `QTO_CHECK_WIRE` |
| 檢查 | 錯誤上色 / 清除上色 | 可保留兩顆或放到操作面板 |

### 方案 C：只顯示操作面板，其餘命令藏在面板內

- Ribbon 只留：
  - `QTO_PANEL`
  - `QTO_RECALC_WIRE`
  - `QTO_EXPORT_JB_SUMMARY`

其餘功能全部放進中文操作面板，減少 Ribbon 混亂。
