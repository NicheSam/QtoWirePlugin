## 已移除的假操作

- `修復／人工確認` 不再未經選擇修整張圖；改為開啟 Review，多選後只修復安全的同步 ID 問題。
- Review 不再提供只存在視窗記憶體的「已處理／忽略」按鈕。
- `QTO_SETTINGS` 不再開啟無法保存的假設定頁，改為開啟實際同步主控；預算版面由「預算表設定」管理。
- 同步主控將重複的「檢查問題」與「修復／人工確認」合併為單一「檢查與修復」。
- 「同步紀錄」會直接捲動並聚焦紀錄區，不再只跳出說明訊息。
- AutoCAD 啟動或開啟 DWG 時不會自動建立、開啟或連結 Excel。

1. 使用兩個 CAD 與預算相符的真實案件，確認 mapping 後的數量與人工預算結果。

3. 使用公司正式共用資料夾測試多人讀取公司規則，以及版本衝突時的提示。
4. 以大型圖面測試複製大量 QTO 物件與移動範圍框時的可接受等待時間。

上述項目不阻擋 `v1.0.1` 發布，但仍是公司正式全面導入前必須完成的實機驗收。
