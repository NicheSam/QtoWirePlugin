# QTO Excel 同步與預算草稿規則

## 使用流程

AutoCAD 啟動與外掛載入時不會自動建立或開啟 Excel，也不會預設啟用同步。

1. 開啟 CAD 圖面後進入 `同步主控`。
2. 需要使用既有預算書時先選擇 Excel；未選擇時，外掛會在圖面旁建立同名 `_QTO_SYNC.xlsx`。
3. 按 `啟用自動同步`。外掛會先更新並開啟 Excel。
4. 後續只要有 QTO 資訊的物件在 CAD 中新增、修改、移動、複製或刪除，CAD 指令結束後就會合併成一次 Excel 更新。
5. `立即重整 Excel` 只用於自動更新失敗、Excel 忙碌或需要強制重套版面。

## 工作簿分層

- `預算草稿`：人員主要整理頁。CAD 控制數量，Excel 保留設備名稱、單位、單價、成本、倍數、廠牌、備註與確認狀態。
- `數量統整`：按系統、設備、計量型態、線材與樓層彙整，供查核數量來源。
- `檢查清單`：顯示缺資料、缺對應與需人工確認事項。
- `CAD原始資料`：每個 QTO 物件一列，由 CAD 完整重建，預設隱藏，需要查核時可由 Excel 取消隱藏。
- `QTO_SYNC_DATA`：同步 ID、Handle、Fingerprint 等技術資料，預設為非常隱藏。

## 預算表設定

`預算表設定`只管理 `預算草稿`的呈現：

- 八個系統的上下順序與顯示狀態。
- 設備、配線、配管、其他工程的上下順序與顯示狀態。
- 人員欄位的顯示狀態。
- 零數量項目是否隱藏。
- 待確認項目是否排在分類最後。

隱藏系統、分類或欄位不會刪除 CAD 原始資料，也不會影響 `數量統整`。

## 同步邊界

- 自動同步是事件式，不是固定秒數輪詢。
- Excel 正在編輯儲存格時可能暫時拒絕 COM 操作；外掛會短暫重試三次，仍失敗才顯示待處理。
- 使用者可在外掛管理區以外建立自己的工作表；更新既有檔案時不得整本覆寫。
- 不支援在 `預算草稿`任意刪除技術 Key 後要求 CAD 推測原列身分。
- 不支援 Excel 反向修改 CAD 幾何、設備數量或位置。
