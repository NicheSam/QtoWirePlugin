# QTO v0.9 預算對應與圖塊更新

## 預算對應

1. 開啟專案 DWG，點選 Ribbon「預算對應」。
2. 按「匯入預算格式」，選擇既有 `.xlsx` 預算書。
3. 左側選擇一個或多個 CAD 計量群組，右側選擇正式預算明細。
4. 選擇受控數量規則與數值，按「建立對應」。
5. 檢查規則後按「確認選取規則」；未確認規則不進正式數量。
6. 按「儲存」後，規則與預算主檔保存於 DWG。
7. 只有確認且可跨案使用的規則，才使用「加入公司規則」。

原始預算工作表不會被修改。外掛更新 `預算草稿`、`QTO_BUDGET_MASTER` 與 `QTO_MAPPING_RULES`，其中後兩頁預設為非常隱藏。

## 數量規則

- 原始數量：加總 CAD QTO 數量。
- CAD 長度：加總 CAD 長度（公尺）。
- 固定數量：只要有符合來源便輸出固定值。
- 乘數：來源數量乘指定倍數。
- 耗損率：來源數量增加指定百分比。
- 每樓層一筆：依有效樓層數乘指定倍數。
- 每區域一筆：依有效區域數乘指定倍數。

## 更新專案圖塊

1. 先儲存 DWG，並確認本圖面已連結標準圖塊資料庫。
2. 點選 Ribbon「更新專案圖塊」。
3. 檢查標準定義與專案定義差異、實例數、屬性及 QTO 影響。
4. 勾選要更新的圖塊，再按「更新勾選圖塊」。

更新器保留插入位置、旋轉、比例、圖層、同名屬性值、可對應動態參數與 QTO XData。來源缺失、匿名圖塊、外部參考及不支援項目不會直接更新。
