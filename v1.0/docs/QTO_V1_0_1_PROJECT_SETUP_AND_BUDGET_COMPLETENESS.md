# QTO v1.0.1 案件設定與預算完整性

## 案件開始

開啟 DWG 後可按 Ribbon 的 `案件設定`。視窗只整合既有資料與工具，不建立第二套專案設定。

| 項目 | 保存位置 | 是否阻擋繪圖 |
|---|---|---|
| 圖塊資料庫 | DWG `QTO_PROJECT_SETTINGS` | 新案建議設定；接手舊圖不阻擋 |
| 預算 Excel | DWG `QTO_PROJECT_SETTINGS` | 否 |
| 正式預算主檔與 mapping | DWG `QTO_BUDGET_PROJECT_V1` | 否 |
| 樓層框與系統框 | 模型空間 Polyline XData | 否 |
| 自動同步 | AutoCAD 執行期 | 否，預設暫停 |

### 操作原則

- 開啟 DWG 不會自動建立或開啟 Excel。
- `選擇`只連結既有 Excel，不立即啟用同步。
- `建立`由使用者指定檔名後建立本案預算 Excel。
- `啟用同步`才會開始監看相關 CAD 指令並更新已連結 Excel。
- 切換 DWG 時會讀取該圖面自己的 Excel 路徑，避免同步到另一案件。

## 預算完整性

`預算完整性`可從 Ribbon、工作流程面板、同步主控或預算對應視窗開啟。

第一版只做可確定的資料檢查：

1. CAD 計量群組沒有 confirmed mapping。
2. CAD 計量群組只有 candidate、needs_review 或 blocked 規則。
3. confirmed mapping 指向不存在、隱藏或非明細預算列。
4. 原始數量或 CAD 長度規則的來源單位與預算單位不一致。
5. 相同 CAD 來源重複 confirmed 到同一預算品項。
6. 正式預算明細目前沒有 CAD 數量來源。

### 人工分類

預算品項不一定來自 CAD。使用者可多選「預算有、CAD 無」項目並標記：

- `人工估算`
- `固定數量`
- `不適用`

分類保存在 DWG 的案件預算資料中，不修改原始預算 Excel。重新匯入或重建 `預算草稿`時仍可追溯。

### 不做的判斷

- 不宣稱預算一定正確或符合契約。
- 不自動把 candidate 升級為 confirmed。
- 不自動判斷設備必須連帶哪些線材、管材與工資；這需要另外建立公司預算組合模板。
- 不讓 Excel 反向修改 CAD 幾何或 QTO 屬性。

## 驗收流程

1. 開啟兩張不同 DWG，分別連結不同 Excel，確認切換圖面不會串錯檔案。
2. 建立一組沒有 mapping 的 QTO 物件，確認出現在「CAD 有、預算無」。
3. 建立 candidate mapping，確認仍列為待確認。
4. 確認 mapping 後重新檢查，確認該 CAD 群組變成已對應。
5. 將工資或固定費用品項標記為人工／固定／不適用，確認不再列為未處理缺口。
6. 更新預算 Excel，確認完整性問題同步進 `QTO_REVIEW`，人工單價與備註仍保留。
