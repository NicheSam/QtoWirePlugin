# QTO v1.0 Beta 操作入口與背景流程

本文件用繪圖員的實際工作順序定義介面邊界。功能存在不代表都應放在 Ribbon；只有需要使用者主動決定的工作才提供按鈕或視窗。

## 日常繪圖入口

| 要做的事 | Ribbon / 視窗入口 | 操作結果 |
|---|---|---|
| 插入公司設備 | `插入圖塊`、`連續放置設備` | 插入圖塊並同時寫入 QTO 預設值與同步 ID |
| 畫配線或管段 | `繪製線管` | 依選取的配線／管段與材料建立標準圖層及 QTO 資料 |
| 接手舊圖 | `轉換舊物件` | 只轉換使用者選取的圖塊、線段與聚合線 |
| 修改單一或多個物件 | `屬性面板` | 修改設備類型、系統、材料、樓層、區域與空間 |
| 快速設定樓層或系統 | `樓層框`、`系統框` | 框內既有 QTO 物件自動取得對應資料；未標註物件不受影響 |
| 找出問題 | `檢查修復` 或同步主控的 `檢查與修復` | 開啟同一份中文檢查清單，可多選、定位、開啟屬性與安全修復 |

## 預算與 Excel

| 要做的事 | 入口 | 操作結果 |
|---|---|---|
| 第一次建立案件預算 | `同步主控` | 選擇既有 Excel 或由外掛建立案件工作簿 |
| 平常同步 | `啟用自動同步` | 相關 CAD 指令結束後合併更新 Excel，不用固定秒數輪詢 |
| 同步異常或強制重套版面 | `立即重整 Excel` | 重新掃描全圖並保留 Excel 人工欄位 |
| 對應正式預算品項 | `預算對應` | 匯入正式預算階層，建立一對多數量規則並由使用者確認 |
| 調整預算草稿顯示 | 同步主控的 `預算表設定` | 調整系統、分類與明細顯示順序，不修改原始預算工作表 |

## 需要獨立視窗的管理工作

| 管理工作 | 入口 | 為何需要視窗 |
|---|---|---|
| 圖塊分類與預設值 | `管理圖塊庫` | 需要搜尋、多選、預覽與批次設定 |
| 專案圖塊更新 | `更新專案圖塊` | 必須比較專案／標準圖塊並由使用者勾選確認 |
| 公司預算規則 | `預算對應` → `公司規則庫` | 需要確認案件規則是否能升級為公司共用規則 |
| 範圍框批次檢查 | 操作面板 → `範圍管理` | 大型圖面可先看影響筆數，再套用或清除設定 |

## 保留的舊圖操作與報表

`操作面板` 保留出線口、箱體、指向箱體、編號標註、線槽尋路及各類 CSV 報表。這些是既有案件或特定配線流程使用的進階工具，不再全部重複放大到 Ribbon 第一層。

## 不提供獨立按鈕的背景工作

- 複製 QTO 物件時重新配發同步 ID。
- 命令結束後批次套用樓層框／系統框。
- 自動同步已啟用時，合併 CAD 變更後更新 Excel。
- 保存圖塊資料庫索引、案件 mapping、公司規則版本與 Excel 技術層。
- 將未確認 mapping、資料缺漏、配線關聯與圖塊版本問題送入檢查清單。

這些背景工作若另做按鈕，會增加繪圖員判斷成本，也容易讓同一流程出現兩種結果，因此只在檢查清單或同步紀錄顯示結果。

## 目前的檢查清單範圍

- 同步 ID 缺漏或重複。
- 系統、設備類型、數量依據、線材與管材缺漏。
- 出線口／箱體未編號或編號重複。
- 出線口未配線、同一出線口多條配線、配線指向不存在的出線口或箱體。
- 長度為 0、圖塊資料庫缺失、圖塊停用／新版／衝突。
- CAD 與 Excel 同步差異、圖塊更新後需人工確認的項目。

安全自動修復目前只處理同步 ID。系統、設備、材料、數量與關聯仍由使用者確認，外掛不得自行猜測。
