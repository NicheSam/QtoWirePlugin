# QTO v1.0 使用流程與介面驗收

本文件不是功能清單，而是用同事實際工作情境檢查入口、主操作、背景行為與錯誤處理。新增功能前應先決定歸屬流程，不得直接在 Ribbon 增加同義按鈕。

## 共通介面規則

- Ribbon 只放高頻入口與必須在圖面中直接執行的命令。
- 超過兩個步驟、需要搜尋、多選、預覽或確認的工作，使用獨立視窗。
- 視窗只保留一個明確主操作；危險、管理或低頻操作降為次要按鈕。
- 可由選取狀態推導的預覽與按鈕啟用狀態應自動更新，不要求使用者再按一次檢查。
- 背景工作不設日常按鈕，只在狀態、同步紀錄或檢查清單顯示結果。
- 所有視窗使用 DPI 縮放、最小尺寸、可捲動內容與中文欄位；技術代碼只作補充。
- 空資料必須說明下一步，不可只顯示空白表格。
- 可預期錯誤必須在視窗內說明並保留使用者操作狀態，不得拋出未處理例外。

## 流程驗收矩陣

| 使用情境 | 主要入口 | 主操作 | 背景處理 | 進階或低頻操作 | 驗收重點 |
|---|---|---|---|---|---|
| 放置標準設備 | 插入圖塊、連續放置設備 | 選圖塊後插入 | 寫入圖塊預設值與同步 ID | 管理圖塊庫 | 未分類圖塊可看見但標為待設定；無資料庫時說明如何選擇 DWG |
| 編輯 QTO 屬性 | 屬性面板 | 選取物件後直接修改 | 選取變更即時刷新 | 舊式批次編輯視窗 | 多選只開放可共同修改欄位；未勾欄位保留原值 |
| 出線口與箱體 | Ribbon、操作面板 | 標記、編輯、指向箱體、編號標註 | 維持 QTO 關聯 | 刪除 QTO 資訊 | 必要舊圖工具保留，不被一鍵流程取代 |
| 線管與線槽 | 操作面板 | 繪製線管或批次尋路 | 計算長度與關聯 | 清除線槽屬性、管段到線槽 | 一般設備工作不必先理解線槽流程 |
| 樓層與系統 | Ribbon 建框、範圍管理 | 建立樓層框或系統框 | 命令結束後套用既有 QTO 物件 | 清除框線設定 | 樓層與系統分開；選取範圍框時自動預覽影響 |
| 找同類物件 | 屬性面板、操作面板 | 勾選欄位後選取相同物件 | 未勾欄位不比對 | 無 | 欄位未勾選時停用輸入；至少一個有效條件才能執行 |
| 檢查與修復 | 檢查修復 | 多選問題後定位或處理 | 彙整同步、mapping、圖塊與資料缺漏 | 安全自動修復 | 不拆成多個檢查視窗；不可自動猜測系統或預算品項 |
| 建立預算 Excel | 同步主控 | 選擇或建立案件 Excel | 依 CAD 更新數量並保留人工欄位 | 預算表設定 | 開啟 CAD 不自動建立或開啟 Excel |
| 正式預算對應 | 預算對應 | 選 Excel、選 CAD 群組與預算品項、建立對應、確認儲存 | 未確認規則不納入正式合計 | 公司規則庫、預算列顯示順序 | 三步驟呈現；空表格要指出尚未匯入；日期或舊資料不得造成崩潰 |
| 公司規則庫 | 預算對應內開啟 | 建立基準、指定案件品項、確認 | 保存版本與案件綁定 | 編輯別名、重新比對 | 指定按鈕必須貼近案件品項選單；不因案件確認自動污染公司規則 |
| 更新專案圖塊 | 更新專案圖塊 | 比較後勾選更新 | 保留位置、屬性、QTO 與同步 ID | 全選可更新 | 必須先預覽與確認；沒有候選時顯示原因 |
| 匯出報表 | 報表、操作面板 | 選擇報表或勾選 CSV 欄位 | 依目前圖面重新計算 | 預算前置 CSV | 報表保留；預算前置 CSV 明確標示不是正式報價表 |

## 這次介面調整

- `預算對應` 改成「選擇預算來源 → 建立對應 → 檢查並儲存」三步驟，並修正空日期資料造成的 JSON 儲存例外。
- `操作面板` 改成「繪圖與連接、整理與檢查、預算與圖塊、報表」四個工作分頁。
- `範圍管理` 選取列後自動預覽影響，保留套用選取、套用全部與清除設定。
- `公司規則庫` 將案件品項選擇、指定與確認放在同一列，降低上下往返。
- `選取相同 QTO` 未勾選的條件會停用，避免看似有值但實際未參與比對。
- `匯出預算前置 CSV` 明確顯示用途、筆數與匯出欄位，並提供可捲動內容。
- `更新專案圖塊` 統一主次按鈕與空狀態，仍維持先預覽、後確認。

## 不在本次重做的介面

- Ribbon 保留既有必要的刪除、編輯、指向箱體、編號標註與報表入口，不因介面整理刪除工作能力。
- 屬性面板、同步主控、圖塊庫管理、插入圖塊、檢查清單與預算表設定已有專用流程，本次只套用共通驗收，不重寫資料邏輯。
- 天花標註與開發測試命令不重新加入主要操作流程。
