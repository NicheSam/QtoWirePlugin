## 操作驗收

請依序操作。成功請勾選；失敗時記下畫面訊息與正在操作的檔案。

- [ ] 開啟 AutoCAD 2023 後，可看到「QTO 弱電計算」頁籤。
- [ ] `run_plugin_self_test.bat` 顯示 `Status=PASS`，且測試結束後工作管理員沒有殘留 `accoreconsole.exe`。
- [ ] 開啟 DWG 時，不會自行建立或開啟 Excel。
- [ ] 「屬性面板」可讀取選取物件，設備、系統、樓層等欄位可修改並儲存。
- [ ] 「插入圖塊」可看到圖塊預覽，並能依原點或中心插入。
- [ ] 「畫配線／管段」可建立物件，屬性面板可立即看到 QTO 資訊。
- [ ] 「樓層框」只修改樓層，「系統框」只修改系統；未標註 QTO 的物件不被寫入。
- [ ] 同步主控只顯示一個「檢查與修復」入口；「同步紀錄」可直接跳到最下方最新紀錄。
- [ ] 檢查清單可多選並定位物件；缺線材、缺管材、重複編號、未配線及無效出線口／箱體關聯可被列出。
- [ ] 純計量配線未建立起終點時不會被誤判；配線與管段不會被要求填設備類型。
- [ ] 「同步主控」可由使用者主動選擇或建立 Excel。
- [ ] 啟用同步後，CAD 指令結束可更新 Excel，人工單價、備註與確認狀態不消失。
- [ ] 「預算對應」可看到 CAD 計量群組與正式預算階層，未確認項目不進正式合計。
- [ ] 「更新專案圖塊」先顯示差異與預覽，只有勾選並確認的圖塊被更新。
