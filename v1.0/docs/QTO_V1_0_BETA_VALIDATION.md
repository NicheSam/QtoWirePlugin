# QTO v1.0 Beta 驗收紀錄

## 版本定位

本版為 `v1.0.0-beta`。核心流程已接通，可供內部試用，但尚未達到正式 `v1.0` 發布門檻。

正式版需再以兩個「CAD 圖面與最終預算書可互相核對」的真實案件驗收。只有預算書、只有 CAD，或兩者不是同一設計版本，都不能視為正式案件驗證。

## 已接通流程

1. 使用者從標準圖塊庫插入設備，或將既有圖塊、線段轉為 QTO 物件。
2. 屬性面板與批量工具維護設備、系統、線材、樓層、區域及空間資訊。
3. 樓層框與系統框依物件位置更新既有 QTO 資訊；未標註 QTO 的物件不會被自動納入。
4. CAD 數量進入 Excel 原始資料，再依已確認的案件 mapping 寫入預算草稿。
5. 公司預算規則只提供可追溯的既有規則；別名或不確定結果仍需使用者確認。
6. 專案圖塊更新前並列顯示目前圖塊與公司標準圖塊，只有勾選並確認後才更新。

## 繪圖員實機驗收清單

以下操作需要 AutoCAD 視窗、滑鼠選點或人工判斷，不能只用 Core Console 取代。

### 標準圖塊與快速繪圖

- 從圖塊庫選擇圖塊時可看到預覽，並可依原點或圖形中心插入。
- 連續放置只需選一次設備，按 Enter 可結束，不會留下未完成物件。
- 直接畫線材或管線後，屬性面板可立即看到 QTO 資訊。
- 轉換舊圖時只處理使用者選取的圖塊、線段與聚合線，不改其他圖面內容。

### 樓層與系統範圍

- 樓層框只改樓層，系統框只改系統。
- 兩種框重疊時，範圍內的 QTO 物件同時取得樓層與系統。
- 沒有 QTO 資訊的物件維持原狀。
- 大型圖面先按「檢查影響」確認筆數，再執行全圖套用。

### 預算與 Excel

- 開啟 DWG 時不會自行建立或開啟 Excel。
- 使用者啟用同步後，CAD 指令完成才合併更新 Excel。
- 預算草稿保留人工輸入的單價、廠牌、倍數、備註與確認狀態。
- 未確認 mapping 顯示在待確認區，不納入正式合計。
- 關閉並重開案件後，公司基準、案件綁定與已確認 mapping 仍可讀取。

### 圖塊更新

- 更新視窗可同時看到專案圖塊與公司標準圖塊。
- 未勾選的圖塊不得更新。
- 更新後位置、旋轉、比例、圖層、同名屬性、QTO 資訊與同步 ID 保留。
- 動態圖塊、匿名圖塊、外部參考或屬性衝突應阻擋或進入檢查清單，不得靜默覆蓋。

## 正式 v1.0 尚缺證據

1. 兩個真實案件的 CAD 數量與最終預算逐系統核對結果。
2. 設備、配線、配管、工資與另料的一對多 mapping 實際確認紀錄。
3. 大型圖面操作時間、卡頓與記憶體使用狀況。
4. 第二台電腦以安裝包執行匯入預算、同步 Excel、插入圖塊與更新圖塊的結果。

上述四項完成前只能發布 Beta，不應將 mapping 結果宣稱為正式契約數量或最終報價。
